# Security policy

## Supported versions

Only the latest release of `io.github.sanamhub:nepdate` and `io.github.sanamhub:nepdate-patro`
on Maven Central receives fixes.

## Reporting a vulnerability

Report privately through
[GitHub security advisories](https://github.com/sanamhub/nepdate-kotlin/security/advisories/new).
Don't open a public issue. Expect a first reply within a week.

Include the library version, the JDK or Android version, and the smallest code that shows the
problem.
